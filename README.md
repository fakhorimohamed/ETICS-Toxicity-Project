# Document Toxicity Analysis

## Overview

This project explores the use of Large Language Models (LLMs) to analyze unstructured documents and transform their content into structured data.

The project focuses on:

* Extracting structured information from documents.
* Analyzing potentially toxic or problematic textual content.
* Storing the extracted information and analysis results in a structured format.
* Exploring the use of LLMs, RAG, and agent-based workflows for document analysis.
